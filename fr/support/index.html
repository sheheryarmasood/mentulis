Comment pouvons-nous t’aider ?

Si tu traverses une crise en ce moment, n’attends pas une réponse par courriel. Appelle le numéro d’urgence local ou trouve une ligne d’écoute sur findahelpline.com.

Comment annuler Premium ?

Ouvre Google Play → ton profil → Paiements et abonnements → Abonnements → Mentulis → Annuler. Sur iPhone : Réglages → ton nom → Abonnements. Désinstaller l’application n’annule pas l’abonnement.

Comment supprimer mes données ?

Dans l’application, va dans Profil → Réinitialiser mes données. Tout ce qui est enregistré sur ton téléphone est effacé. Si tu as créé un compte, tu peux aussi nous demander sa suppression par courriel.

J’ai oublié mon code

Sur l’écran de verrouillage, touche « Code oublié ». Pour protéger ta confidentialité, cela réinitialise l’application et efface tes données sur ce téléphone : pense à les exporter de temps en temps.

Je ne reçois pas les rappels

Vérifie que les notifications sont autorisées pour Mentulis dans les réglages du téléphone et que l’économiseur de batterie ne bloque pas l’application en arrière-plan.

Questions sur une réservation ou une séance

Pour modifier une séance, contacte directement ta ou ton psychologue ou passe par la réservation dans l’application. Pour un problème de paiement, écris-nous.
